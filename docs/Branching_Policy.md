# Branch Naming Convention

All branches must adhere to the following naming conventions:

- `feature/<ticket-id>-<short-description>`: For new features.
- `bugfix/<ticket-id>-<short-description>`: For bug fixes.
- `hotfix/<ticket-id>-<short-description>`: For urgent fixes in production.
- `release/<version>`: For preparing releases.

Examples:
- `feature/LATP-01-dashboard`
- `bugfix/LATP-45-login-crash`
